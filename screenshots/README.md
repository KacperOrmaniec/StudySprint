# Zrzuty ekranu

Umieść tutaj zrzuty ekranu aplikacji wykorzystywane w głównym `README.md`.

## Wymagane pliki

| Nazwa pliku    | Ekran                              |
| -------------- | ---------------------------------- |
| `home.png`     | Ekran główny (podsumowanie)        |
| `subjects.png` | Przedmioty (lista + dodawanie)     |
| `tasks.png`    | Zadania (filtry, lista, formularz) |
| `timer.png`    | Timer Pomodoro                     |
| `stats.png`    | Statystyki                         |

Opcjonalnie `demo.gif` — krótki GIF pokazujący przepływ w aplikacji.

## Jak zrobić zrzuty

**Telefon (Expo Go):**

- Android: przycisk zmniejszania głośności + przycisk zasilania.
- iOS: przycisk boczny + zwiększania głośności.

**Emulator / symulator:**

- Android Emulator: ikona aparatu na pasku narzędzi (zapis do `~/Desktop`).
- iOS Simulator: `Cmd + S` (zapis na pulpit).

**Web (`npm run web`):**

- Narzędzie do wycinka Windows: `Win + Shift + S`.

## Jak nagrać GIF (opcjonalnie)

- Windows: [ScreenToGif](https://www.screentogif.com/).
- iOS Simulator: `xcrun simctl io booted recordVideo demo.mov`, potem konwersja do GIF.

> Po dodaniu plików obrazy automatycznie pojawią się w sekcji „Zrzuty ekranu"
> głównego `README.md` (ścieżki są już podpięte).
